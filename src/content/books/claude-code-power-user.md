Claude Code is not another chat window with a code-completion plugin. It's an agentic CLI tool that reads your codebase, edits across multiple files, runs your tests, executes shell commands, talks to your databases through MCP servers, and ships features while you watch.

But most developers are still using it like a fancier autocomplete.

*Claude Code: The Power User Guide* is the practical, hands-on book for developers who want to make Claude Code an integral part of how they ship software — not a novelty they reach for once a week.

## What's inside

**Set up correctly.** Installation on macOS, Linux, and Windows (WSL). API key vs. Claude Max/Pro auth. The CLAUDE.md system at the project, user, and directory level. VS Code and JetBrains integrations. The permission model.

**Master the core workflows.** Code generation that respects your conventions, multi-file refactoring, debugging across layers, test generation, and documenting undocumented codebases — each chapter ends with a real-world workflow.

**Work at scale.** Strategies for monorepos and large codebases, the /compact command, coordinated multi-file operations, migrations (e.g., JavaScript to TypeScript), and adding cross-cutting concerns like auth or observability across an entire application.

**Customize and integrate.** Hooks for pre-tool and post-tool automation, MCP servers (GitHub, PostgreSQL, Slack, custom), the Claude Agent SDK for building your own agents, and IDE integration patterns.

**Apply it to real work.** Frontend (React/Vue/Angular), backend (APIs, schemas, auth, jobs), DevOps (Docker, CI/CD, Terraform, Kubernetes), and onboarding to an existing codebase — including the legacy Rails app nobody wants to touch.

**Operate safely.** The permission model in depth, sandboxing, .env and credential handling, code review for AI-generated code, cost management with /cost, team CLAUDE.md conventions, and enterprise security considerations.

**CLAUDE.md templates** for web apps, mobile apps, CLI tools, libraries, monorepos, and data pipelines — each with project overview, architecture, conventions, and common-task scaffolding.

If you've installed Claude Code, run a few commands, and wondered what you're missing — this is the missing manual.

Includes coverage of Claude Opus 4.6 and Sonnet 4.6 in Claude Code, the CLAUDE.md system, hooks, MCP, the Agent SDK, IDE extensions, and every 2026 power-user capability.
