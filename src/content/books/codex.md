For years, AI meant autocomplete: you typed, it finished the line, you stayed in the driver's seat. Then the pattern flipped. Instead of asking an AI to finish your line, you hand it the whole task — "fix the failing tests in the billing module," "add pagination to the admin table," "find out why the deploy is slow" — and do something else while it works. When it's done, you review what comes back the way you'd review a pull request from a teammate. The AI stops being a faster keyboard and becomes something you delegate to.

Codex is OpenAI's tool for that shift, and the one that turned delegation from a feature into a habit — because it puts the same GPT-5–powered agent on every surface where a developer already works: the terminal, your editor, a desktop app, a cloud workspace in the browser, a GitHub pull request, a Slack channel, and your phone. Assign a task from wherever you are; review the result from wherever you end up.

*Codex: The Complete Guide* takes you from first install to confident daily use — and, just as importantly, to using an agent safely.

## Inside, you'll learn how to

- Choose the right plan and get set up on the CLI, the editor extension, and the desktop app
- Match each surface — terminal, editor, web, phone, SDK, Chrome/MCP — to the work it does best
- Delegate real work: cloud tasks, tagging Codex on GitHub PRs, automated code review, and Slack
- Write task prompts that come back right, and review what returns like a pull request
- Use AGENTS.md to give the agent project context, and set approvals and sandboxing it can't cross
- Manage cost and usage, and apply solo, team, and enterprise patterns
- See where Codex fits beside the other coding agents you may already use — and where it gets things wrong

Codex's power and its risk come from the same source: a tool that can read your whole repository, run commands, edit across many files, and open a pull request is a tool you have to supervise. This book takes both halves seriously — the chapters on extracting value are matched by honest chapters on review, boundaries, and security.

**Who it's for:** working developers who want to use Codex well rather than demo it once; engineers comparing tools; team leads weighing it for real use; and technically comfortable non-specialists who can drive a terminal and read a diff. You don't need to be an expert in any language — you do need to be willing to review what an agent hands back. That reviewing muscle is the load-bearing skill of the delegation era, and this book builds it.
